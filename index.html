O que é o Bloquin
Um IDE feito para aprender

Como o Scratch, mas para hardware de verdade. Blocos visuais que geram código C++ e enviam direto para a placa.

🧩
Blocos em português

👁️

Compilar com um clique
arduino-cli incluso. Funciona 100% offline. Compila e grava na placa sem instalar mais nada.

Por que usar o Bloquin em sala?

Pensado desde o início para o ambiente escolar — sem dependências, sem cadastros, sem complicação.

01
Zero configuração
Instale uma vez e funciona em todos os computadores do laboratório. Sem Node.js, sem Python, sem drivers extras — tudo incluso.
02
Funciona offline
Escolas com Wi-Fi limitado ou sem internet podem usar normalmente. Compilação e upload são 100% locais.
03
Interface em português
Sem barreira de idioma para alunos do ensino fundamental e médio. Nomes dos blocos em português do Brasil.
04
Ponte para o código real
O código C++ gerado é exibido em tempo real. Alunos avançados podem migrar para o código puro quando estiverem prontos.
